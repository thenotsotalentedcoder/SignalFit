# AI disclosure

SignalFit's planned application provider is Gemini through the official `@google/genai` SDK. The API key will remain server-only and structured responses will be validated before use.

This foundation was built with AI-assisted development (Kimi, as requested in the project brief). UI uses original project code and standard Next.js, React, Tailwind CSS, PostgreSQL, bcryptjs, otplib and Zod dependencies under their respective licenses. No Supabase SDK or older project code is used.
